    Doubly linked list

    Front is most recent. The node at the back is evicted next.

      The four policies

      LRU
      Evicts whatever was used longest ago. Built from a hash map and a doubly linked list, so every access is O(1).
      FIFO
      Evicts whatever arrived first, even if it is still in use. A queue plus a set. It can get worse with a bigger cache, which is Bélády's anomaly.
      LFU
      Evicts whatever has been used the fewest times, breaking ties by recency. A map from use count to linked list gives O(1).
      Optimal
      Evicts whatever is needed furthest in the future. No real system can know that, so it serves as the best possible score to compare against.
